# 한계와 해석 경계

1. FlyVis는 초파리 시각계의 계산 모델이며 초파리 EEG 측정값이 아닙니다.
2. THINGS-EEG2 분석은 사람이 이미지를 볼 때의 EEG입니다. 심상을 떠올리게 한 EEG가 아니므로 심상 해독 성능을 말할 수 없습니다.
3. 두 시스템은 측정 단위, 차원, 시간척도와 학습 목표가 다릅니다. RSA는 표상 거리 구조의 유사도만 요약합니다.
4. FlyVis는 optic-flow 과제에서 학습된 모델입니다. 정지 자연 이미지 반응을 인간 물체 인식과 같다고 가정하면 안 됩니다.
5. 이미지 5개라면 독립 RDM 거리쌍이 10개뿐입니다. p값은 매우 거칠고 결과는 디버깅/시연용입니다.
6. 한 참가자·한 세션은 인구 수준 결론을 허용하지 않습니다.
7. 결과가 나오더라도 종간 공통 표상이나 의식의 증거가 아니라 추가 실험을 정하는 탐색 결과입니다.
