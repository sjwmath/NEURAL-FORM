# 연구 계획

## 질문

동일한 시각 자극 집합에 대해 초파리 시각계 계산 모델의 표상 거리 구조와 인간 시각 유발 EEG의 표상 거리 구조가 어느 정도 함께 변하는가?

## 목표와 비목표

첫 목표는 측정 가능한 표상 유사도를 재현 가능한 코드로 계산하는 것이다. 이 분석은 인간의 심상(mental imagery), 파리의 마음, 종간 의식의 동일성을 판정하지 않는다. THINGS-EEG2는 이미지 관찰 EEG이지 심상을 떠올리는 과제가 아니다.

## 단계

1. 5개 이미지에서 파일-ID 연결과 전체 파이프라인의 동작을 확인한다.
2. 20–100개 이미지에서 이미지 수/특징 정의에 대한 안정성을 확인한다.
3. 다수 참가자와 세션에서 반복하고 신뢰구간과 교차검증을 추가한다.
4. 동적 자극·방향 민감도와 시간에 따른 FlyVis/EEG 표현을 비교한다.
5. 심상 연구로 확장하려면 별도의 심상 과제 데이터와 독립 평가 설계를 먼저 확보한다.

## 성공 기준

- 실제 메타데이터를 통한 정확한 이미지-ID-EEG 매칭
- 저장된 특징, RDM, 실행 설정과 검증 가능한 로그
- 결과를 탐색적 분석으로 제한하고 음성 결과도 그대로 보고
